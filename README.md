# A股日线三态趋势识别工具（ginkgo-nut_t）

只用**均线 + ADX** 把每只标的的日线行情判成 **多头 / 空头 / 震荡** 三态（内部再分强 / 弱两档），
在日 K 上标出波段与趋势切换点，每个交易日盘后（默认 15:35）自动重跑一次，
并把**趋势播报**推送到飞书（趋势切换按 🔴🔴 / 🟡 分级提醒）。

> **只做行情识别**：不产生任何买卖点位、不算仓位与收益、不接下单接口。
> 完整口径与边界见 [需求文档.md](需求文档.md)（唯一权威说明，页面 `/doc` 可在线查看）。

## 快速开始

```bash
./run.sh                  # 等价于 PYTHONPATH=./libs: python3 app.py
# 浏览器打开 http://127.0.0.1:8899
```

依赖已随仓库放在 `libs/`（`PYTHONPATH=./libs:` 即可运行），系统需要 Python 3.8+ 与
pandas / numpy / flask / requests / yaml。

## 页面

| 路径 | 作用 |
|---|---|
| `/` | 趋势仪表盘：逐只三态（含强/弱）+ 本波段第几日 + 今日切换(🔴🔴/🟡) + 酝酿中(⏳) + **判定规则与运行机制** |
| `/stock/<code>` | 个股详情：判据自证卡（强/弱档 + ADX）+ 四宫格 K 线（背景色块=波段，◆=分级切换点）+ 波段明细（含段内强日）|
| `/market` | 行情波段：选区间选标的，看三态天数构成（含强档天）、波段性格统计、逐票 K 线（可现场改参数）|
| `/stocks` | 标的管理（只有代码与名称） |
| `/settings` | 三态参数（悬停看解释）、盘后自动运行、飞书通道 |
| `/doc` | 需求文档 |

## 飞书推送

设置页二选一：

1. **群机器人 Webhook**（最省事）：填 Webhook 地址，机器人开了"加签"就把密钥一起填。
2. **企业自建应用机器人**（可私聊直达）：填 App ID / App Secret / 接收者 ID 与类型。

到点后自动「更新数据 → 三态扫描 → 趋势播报」；节假日数据不更新时自动跳过，不打扰。

## 三态判据（一句话版）

- 多头：**强** = `收盘 > MA20` 且 `MA20 > 慢线` 且斜率 `> +slope_min` 且 `ADX(14) > adx_min`；
  **弱** = 只满足“收盘在 MA20 上方且斜率为正”
- 空头：与上面完全对称（收盘在 MA20 下方、MA20 在慢线下方、斜率够负、ADX 够大）
- 震荡：其余；均线没算出来：不判定
- 毛刺过滤：持续不足 `spike_days` 日的片段并入相邻主状态，不成波段（避免标注闪烁）
- 新状态要连续 `confirm_days` 天才切换（滞回），凑满之前叫"酝酿中"
- `slope_min` / `adx_min` **只决定强与弱，不改变三态归属**
- BOLL(20,2) 的 `%B` **不参与判定**，只给震荡段做区间定位（趋势段停手）
