# A股日线三态趋势识别工具（ginkgo-nut_t）

两层结构，都用**同一份**结果渲染：

- **判定层**：只用**均线 + ADX** 把每只标的的日线行情判成 **多头 / 空头 / 震荡** 三态（内部再分强 / 弱两档），
  在日 K 上标出波段与趋势切换点。
- **提示层**：在**已判定的震荡段**里按区间纪律提示买入 / 卖出 / 止损，在多头段提示“回踩 + 缩量 + 止跌”介入（附最高风险）。

每个交易日盘后（默认 15:35）自动重跑一次，把**趋势播报**推送到飞书
（趋势切换按 🔴🔴 / 🟡 分级提醒，区间纪律提示单独成节 🎯 / 🔵）；趋势播报后会**追发一轮卖出预警扫描**，仅当出现红/黄信号才推第二条（0 预警当天不打扰，v3.3.10）。

**独立功能群（v3.3）——卖出通知工具**：**复用趋势清单**（每票多一个「估值口径类型 / 行业指数 / 纳入开关」列），对纳入的每只票跑 **A 估值过高 / B 基本面恶化 /
C 行业与宏观 / D 社保与保险卖出** 四路信号，命中按 🟡/🔴 预警；**一个功能一个界面**——`/sell` 单页展示逐股信号卡片，因子/通知配置做成可折叠区，回测走独立页（只出风险预警、不接管下单，详见需求文档第 10 节）。

> **边界**：不给仓位金额、不算收益与胜率、不记账、不接任何下单接口 —— 提示层只说纪律，不说交易。
> 完整口径与边界见 [需求文档.md](需求文档.md)（唯一权威说明，页面 `/doc` 可在线查看）。

## 快速开始

```bash
./run.sh                  # 等价于 PYTHONPATH=./libs: python3 app.py
# 浏览器打开 http://127.0.0.1:8899
```

依赖已随仓库放在 `libs/`（`PYTHONPATH=./libs:` 即可运行），系统需要 Python 3.8+ 与
pandas / numpy / flask / requests / yaml。

## 飞书推送

设置页二选一：

1. **群机器人 Webhook**（最省事）：填 Webhook 地址，机器人开了"加签"就把密钥一起填。
2. **企业自建应用机器人**（可私聊直达）：填 App ID / App Secret / 接收者 ID 与类型。

到点后自动「更新数据 → 三态扫描 → 趋势播报」；节假日数据不更新时自动跳过，不打扰。
仪表盘上还有“飞书播报预览(dry)”按钮，只生成文本不发送。

## 三态判据（一句话版）

- 多头：**强** = `收盘 > MA20` 且 `MA20 > 慢线` 且斜率 `> +slope_min` 且 `ADX(14) > adx_min`；
  **弱** = 只满足“收盘在 MA20 上方且斜率为正”
- 空头：与上面完全对称（收盘在 MA20 下方、MA20 在慢线下方、斜率够负、ADX 够大）
- 震荡：其余；均线没算出来：不判定
- 毛刺过滤：持续不足 `spike_days` 日的片段并入相邻主状态，不成波段（避免标注闪烁）
- 新状态要连续 `confirm_days` 天才切换（滞回），凑满之前叫"酝酿中"
- `slope_min` / `adx_min` **只决定强与弱，不改变三态归属**
- BOLL(20,2) 的 `%B` **不参与判定**，只给震荡段做区间定位与提示阈值

## 提示层纪律（一句话版）

- 震荡段：`%B ≤ buy_pctb(0.10)` 🟢 买入提示（同时开段内跟踪，止损位 = 当日收盘 −`stop_pct(5)%`）；
  跟踪中 `%B ≥ sell_pctb(0.90)` 🔺 卖出提示；最低价碰到止损位 🛑 止损提示；
  持满 `max_hold(15)` 日仍未到上沿 ⌛ 超期提示；中间状态 🔵 持仓中 / ⚪ 等待
- 同时命中只出一个：**止损 > 上沿卖出 > 超期**
- **震荡 → 空头 = 🛑 止损回避**（下沿买入逻辑当场失效）
- 多头段介入要三条全凑：**回踩 MA20（容差 `pb_touch`%）+ 缩量（量比 < `vol_shrink`×）+ 收盘止跌**，
  并附**最高风险**警示；缺项只给 ⚪ 介入观察并列出还差哪条
- **第一纪律：趋势段停手** —— 不是震荡段就一律 ⛔ 不给区间提示（结构性停手，不是文案过滤）
- 关掉 `t_trade.enabled` 后，页面与推送回到"只报三态与切换分级"


测试同时充当护栏：页面与推送里不允许出现**交易口径**用词（仓位金额、收益胜率、模式网格、
止盈/低吸/高抛、点位与下单指令），并用 `TIP_WORDS` 反向兜底确保**纪律提示本身**确实写进了页面与播报。
