均线 + ADX 判据 唯一的环境判定层

判据（四条全满足才计强）：收盘 > MA20 且 MA20 > MA{{ rg.ma_slow }} 且 MA20 的 5 日斜率 > +{{ rg.slope_min }}% 且 ADX(14) > {{ rg.adx_min|int }} → 多头； 完全反向 → 空头；其余（价格反复穿越 MA20、斜率走平）→ 震荡。 只满足“收盘在 MA20 一侧 + 斜率同向”时记弱多头 / 弱空头（三态归属不变，只降级标注）。 新状态要连续 {{ rg.confirm_days }} 日才切换；持续不足 {{ rg.spike_days }} 日的片段并入相邻主状态，不成波段。 中线固定 MA20（写死在 core/regime.py），快线只用于展示与辅助。改这里会同时改变股票行情页的色块划分、仪表盘三态与每日飞书播报——三处读同一份结果。

震荡段做T提示 提示层：只给纪律提醒

纪律原文：震荡段 %B ≤ {{ tt.buy_pctb }} 提示买入 / %B ≥ {{ tt.sell_pctb }} 提示卖出 / 自提示买入当日收盘 −{{ tt.stop_pct }}% 硬止损 / 最长持 {{ tt.max_hold }} 日；震荡 → 空头 = 止损回避；多头段要“回踩 MA20（最低价距均线 {{ tt.pb_touch }}% 以内）+ 缩量（量比 < {{ tt.vol_shrink }}×）+ 收盘止跌”三条全凑才给介入提示，并附最高风险警示。 第一纪律是趋势段停手：提示只在已判定的震荡波段里成立，空头段一律不给。段内的持仓回放只用来回答“今天该提示买入、卖出还是止损”，不记账、不算收益与胜率、不给仓位金额、不接入任何下单接口。
