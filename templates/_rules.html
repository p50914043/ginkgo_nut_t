一、三态判定（日线收盘，仅用均线 + ADX）

① 多头　收盘 > MA20 且 MA20 > MA{{ rgp.ma_slow }} 且 MA20 斜率 > +{{ rgp.slope_min }}% 且 ADX(14) > {{ rgp.adx_min|int }} 弱多头：价在 MA20 上方且斜率为正
② 空头　收盘 < MA20 且 MA20 < MA{{ rgp.ma_slow }} 且 MA20 斜率 < −{{ rgp.slope_min }}% 且 ADX(14) > {{ rgp.adx_min|int }} 弱空头：价在 MA20 下方且斜率为负
③ 震荡　其余情况（价格反复穿越 MA20、斜率走平） {{ regime_desc.range }}
④ 毛刺过滤　状态持续不足 {{ rgp.spike_days }} 日的片段并入相邻主状态 避免标注闪烁
⑤ 滞回确认　新状态需连续 {{ rgp.confirm_days }} 个交易日成立才切换 没凑满 = 酝酿中 ⏳，不改今日口径
⑥ 数据不足　MA20 / 慢线 / 斜率任一项还没算出来 {{ regime_desc.unknown }}
  • 中线固定 MA20（不开放修改），斜率口径 (MA20[t]−MA20[t−5])/|MA20[t−5]|×100； 快线 MA{{ rgp.ma_fast }} 只在图上做辅助参考，不参与判定。
  • 强 / 弱两档：四条全满足 = 强；只满足“收盘在 MA20 一侧 + 斜率同向” = 弱（三态不变，标签写作弱多头 / 弱空头）。
  • 波段标注：K 线背景色块 = 生效状态的连续段，◆ = 趋势切换确认那天；段内涨跌取段首末收盘，高低取段内极值。
  • BOLL(20,2) 不参与三态判定，只用于震荡段的区间定位：%B = (收盘 − 下轨) / (上轨 − 下轨)， 0 靠下轨、1 靠上轨；仪表盘与详情页的“区间位置”列就是它。震荡做T的第一纪律：趋势段停手 ——历史实证（7 只大盘股、2.1 年）：只在震荡段内 %B≤0.10 买 / %B≥0.90 卖、最长持 15 日、5% 止损， 27 笔胜率 70%、均净 +1.68%；同样的信号放在趋势段只有 52% 胜率、均净 +0.28%。 本工具已删除交易层，不再重跑这套账，上面数字是历史结论的引用，页面只提供 %B 定位。
